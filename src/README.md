# Vehicle Rental System

A simple Java Object-Oriented Programming project that simulates a vehicle rental system. The system supports different types of vehicles such as Cars and Bikes.

## Features

- Create and manage different types of vehicles
- Store vehicle number, brand, and rental price
- Store type-specific information
  - Car: Number of seats
  - Bike: Engine capacity
- Display vehicle details
- Calculate rental amount based on rental duration
- Demonstrate inheritance, abstraction, encapsulation, and polymorphism
